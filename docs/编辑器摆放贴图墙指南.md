# 编辑器摆放贴图墙指南

## 核心思路

关卡墙壁不再需要代码生成。把 PNG 拖进场景、挂上 `paint_wall.gd` 脚本，墙就自动获得：
- 贴图显示（优先使用你拖进来的 PNG）
- 与贴图尺寸一致的矩形碰撞（可调 `pixels_per_unit`）
- 光滑/粗糙物理属性（`smooth` 勾选）——光滑墙反射胶球，粗糙墙阻挡胶球

## 组件说明

脚本：`res://scripts/gameplay/paint_wall.gd`（`StaticBody2D`）

| 属性 | 类型 | 说明 |
|---|---|---|
| `texture` | Texture2D | 手绘贴图，留空则用 `size_px` 占位 |
| `smooth` | bool | true = 光滑墙（层位 2，反射胶球）；false = 粗糙墙（层位 1，阻挡胶球） |
| `pixels_per_unit` | float | 贴图像素换算世界单位的比例，默认 `100`（100px = 1m） |
| `size_px` | Vector2 | 无贴图时的占位尺寸（像素） |

## 操作步骤

1. 把 PNG 拖进项目面板的 `res://assets/walls/`（目录不存在就新建）。

2. 新建关卡场景，Add Child（Ctrl+A）→ StaticBody2D，或直接把 PNG 从文件系统拖进场景树（自动创建 Sprite2D）。

3. 给 StaticBody2D 挂上脚本：
   - 选中节点 → 节点检查器上方 `Script` 槽 → 点击并选择 `paint_wall.gd`。

4. 设置属性：
   - `texture`：拖入 PNG。
   - 或 PNG 作为 Sprite2D 子节点挂在墙下（脚本自动读取该子节点的纹理）。
   - `smooth`：勾选 = 光滑。**光滑只影响物理，不改贴图颜色**。

5. 摆放/旋转/复制墙面搭关卡。碰撞形状会在运行时按贴图尺寸自动生成，无需手调。

## 示例关卡

`res://scenes/levels/paint_lab.tscn` 是已搭好的起点（地板 + 左右边界 + 一面光滑架墙 + 一面粗糙方石），每面墙均为 `paint_wall.gd` 组件：

- 直接打开并在编辑器里移动它们。
- 运行时验证：F5 运行（或把主场景临时切到 paint_lab）。
- 想上手手绘墙：把贴图拖进 `ShelfSmooth.texture` 即替换该墙外观。

注意：`player_test.tscn`（主场景）保持代码生成不动；你新建或编辑关卡完全是手工 `.tscn`，两者互不影响。
