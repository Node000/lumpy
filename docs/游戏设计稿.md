# lumpy设计稿

平台跳跃+简单解谜

单元关卡制，即每关独立场景。

## 玩家操作

主角是一个白色的核心，身上沾附着类似液态的白色胶球，玩家可以控制角色移动。

A/D左右移动

Space跳跃（根据按住时间调整跳跃高度，松开即停止，要有跳跃高度上限，要有土狼时间）

鼠标左/右键分别为吐/吸胶球

R键为当前关键快速重开

### 胶球机制

按住鼠标左键持续逐颗吐胶球（主角有对应动画）

吐球会消耗身上的胶球量

鼠标右键吸胶球（主角有对应动画）

吸球可以补充身上的胶球量

玩家身上的胶球数量会影响其跳跃高度。（提供参数，要求是影响上限和最大影响系数（用于调控最低高度和每个胶球带来的高度））

#### 关于胶球

胶球是一个白色圆形，不使用起伏、收缩、呼吸或液体 shader 效果。

碰撞体为圆形，半径比视觉半径小约 16.7%，以减少小球之间和小球与墙面的卡碰。

被玩家发射后保持直线运动，飞行超过 6 秒仍未命中障碍时回到对象池。

运动的胶球碰撞到任意非光滑墙壁/胶球时停止运动。静止约0.2秒后会弹性放大到2倍大小（膨胀），视觉与碰撞同步增长。

运动的胶球碰到任意光滑墙壁后会沿碰撞箱被偏转并继续运动，直到碰到其他类型的障碍。

停止运动的胶球属于非光滑墙壁，玩家可以踩在上面或被阻挡。

玩家的体型和碰撞箱会随着身上的胶球增多而变大，胶球按固定布局附着在主角身上，不使用液体流动、起伏或呼吸效果。

## 其他开发注意事项

1.准备一套音频系统，要求允许跨场景，有SFX和BGM的播放以及音量设置，最多并行播放6个SFX的音效

2.准备一个圆形划像转场（转场背景可以设置贴图或者对象，方便后续加入转场背景），中心位置为主角所在位置，需要可以调整转场的持续时间和运动曲线（默认线性）

3.角色的移动速度、最大跳跃高度、胶球对跳跃的影响参数和最大影响上限、胶球的飞行速度、连续吐球间隔、吐球散布、吸球角度和吸球半径等游戏属性都需要放在一个文件/对象内统一调整（要求方便快速调整测试效果）
