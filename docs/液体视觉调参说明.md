# 液体视觉调参说明

项目的视觉参数集中在 `scripts/core/gameplay_tuning.gd`。修改后重新运行项目即可看到结果；如果修改了 builder 中的场景初始值，需要重新运行对应 builder。

## 常用参数

### 角色贴图大小

角色贴图由 `builders/build_player_test.gd` 创建，搜索：

```gdscript
animated.scale = Vector2(0.72, 0.72)
```

- `0.72` 改大，角色贴图整体变大。
- `0.72` 改小，角色贴图整体变小。
- 例如 `Vector2(0.85, 0.85)` 会比当前大约 18%。
- 贴图原点由 `animated.position` 控制：

```gdscript
animated.position = Vector2(0, -15)
```

第二个数变小，贴图向上移动；变大，贴图向下移动。

修改后运行：

```text
godot --headless --path . --script res://builders/build_player_test.gd
```

### 自由胶球大小

在 `scripts/core/gameplay_tuning.gd` 中调整：

```gdscript
var glue_ball_radius := 8.5
var glue_ball_collision_radius := 8.5
```

- `glue_ball_radius` 控制自由胶球视觉半径。
- `glue_ball_collision_radius` 控制碰撞半径。
- 两者通常保持相同。
- 胶球直径约为角色可见高度 40% 的当前默认值是 `8.5` 半径。

静止胶球的延迟膨胀：

```gdscript
var glue_swell_delay := 2.0
var glue_swell_scale := 1.35
var glue_swell_collision_factor := 1.2
```

- `glue_swell_delay`：静止多久后开始膨胀。
- `glue_swell_scale`：视觉最大膨胀倍数。
- `glue_swell_collision_factor`：碰撞体最大膨胀倍数。

### 胶球集合大小

```gdscript
var player_collection_radius_base := 15.0
var player_collection_radius_per_glue := 3.3
var player_collection_max_radius := 54.0
```

- `player_collection_radius_base`：没有额外胶球时的集合基础半径。
- `player_collection_radius_per_glue`：每增加一个胶球，集合增加多少。
- `player_collection_max_radius`：集合最大半径。

如果想让集合长得更快，增大 `player_collection_radius_per_glue`；如果想限制最大体积，减小 `player_collection_max_radius`。

### 集合底部位置

```gdscript
var player_collection_bottom_y := 14.0
```

这个值是相对玩家根节点的局部 Y 坐标：

- 数值增大，集合整体向下，底部更靠近脚。
- 数值减小，集合整体向上，脚部露出更多。
- 增长过程中底部会保持在这个位置，集合中心会自动向上移动。

### 液体扭曲强度和速度

```gdscript
var glue_visual_flow_speed := 1.35
var glue_visual_distortion := 0.075
var glue_visual_edge_softness := 0.055
```

- `glue_visual_flow_speed`：内部液体涌动速度。
- `glue_visual_distortion`：液体表面扭曲强度。
- `glue_visual_edge_softness`：边缘软化宽度。

推荐调参顺序：先改 `glue_visual_distortion`，再改 `glue_visual_flow_speed`，最后微调 `glue_visual_edge_softness`。

### 融球颜色与渲染层级

```gdscript
var player_body_color := Color(0.98, 0.965, 0.953, 1.0)
```

- `player_body_color`：玩家身上融球集合的颜色，默认与角色贴图身体色一致。
- 集合的 `z_index` 为 `3`，角色贴图 `z_index` 为 `2`，因此融球集合会覆盖在贴图上方。
- 如果想让贴图重新覆盖融球，调整 `scripts/gameplay/blob_backdrop.gd` 中的 `z_index = 3` 为小于 2 的值（例如 `1`）。

### 小球团块与环绕涌动

玩家身上的集合由多个独立小球构成，每个小球围绕中心环绕并轻微涌动，而不是全部融合成一个光滑大球。

关键参数（`scripts/core/gameplay_tuning.gd`）：

```gdscript
var collection_bubble_core_radius := 7.0
var collection_bubble_radius := 5.0
var collection_bubble_surface := 1.2
```

- `collection_bubble_core_radius`：中心核心小球的半径。
- `collection_bubble_radius`：每颗环绕小球的半径。
- `collection_bubble_surface`：融球表面阈值；值越大小球越容易分离、凸起越明显；值越小越容易融合成团。

环绕运动逻辑在 `scripts/gameplay/blob_backdrop.gd` 的 `_orbit_offset()`：

- 每颗球有独立的轨道半径、角速度和相位。
- 轨道半径是集合半径的 `0.22 ~ 0.52` 倍，小球不会飞出集合。
- 每颗球沿径向有呼吸式摆动。
- 增加胶球数量时，新小球会在自己轨道上自然出现，不会突然弹出。

想改变观感：

- 想让小球更明显：调大 `collection_bubble_radius`，或调大 `collection_bubble_surface`。
- 想让小球聚得更紧：调小 `collection_bubble_core_radius`，或调小 orbiter 数量（改 `blob_backdrop.gd` 中 `count` 的乘数）。
- 想让涌动更快：调整 `blob_backdrop.gd` `_orbit_offset()` 中的 `angular_speed` 和 `sin()` 频率。

### 碰撞箱大小

```gdscript
var body_radius_base := 17.0
var body_radius_per_glue := 1.35
var body_collision_max_radius := 28.0
var body_collision_bottom_offset := 16.0
```

- `body_radius_per_glue`：每颗胶球增加的碰撞半径，当前为 `1.35`（比视觉集合增长 `3.3/球` 慢很多）。
- `body_collision_max_radius`：碰撞箱最大半径。
- `body_collision_bottom_offset`：碰撞箱底部相对玩家原点的固定距离（脚的位置）。
- 碰撞箱底部固定不会把角色顶起；半径增加时碰撞箱向上扩展。

### 吸球扇形角度与鼠标指向

```gdscript
var suck_cone_angle_deg := 30.0
```

- `suck_cone_angle_deg`：吸球扇形**全角**，一半为 `15°`，默认 `30°`。
- 扇形中心线 360° 跟随鼠标位置；按住右键移动鼠标即可旋转。
- 吐球与吸球一样，弹丸方向跟随鼠标 360° 旋转。
- 调大数值（如 `60.0`）扇形变宽；调小（如 `15.0`）变窄。
- 鼠标指向仍然受墙体视线检测约束，墙后胶球不会被吸。

## 胶球集合中心对象位置

集合是玩家节点 `VisualBlob` 下的 `LiquidCollection` 精灵，集合的源点布局在 `scripts/gameplay/blob_backdrop.gd` 的 `_source_for_index()`：

```gdscript
var layouts := [
    Vector2(0.0, 0.0),
    Vector2(-10.0, 1.0), Vector2(10.0, 1.0),
    ...
]
```

- X 为左右位置，负数向左，正数向右。
- Y 为相对集合中心的位置，负数向上，正数向下。
- 想让集合顶部更丰满，调高顶部源的负 Y 绝对值。
- 想让集合两侧更宽，调大左右源的 X 绝对值。
- 不建议直接修改 `VisualBlob.position`，因为它会破坏底部锚定公式。

底部锚定公式是：

```gdscript
position.y = _bottom_y - radius
```

如果需要整体调整集合底部，请改 `player_collection_bottom_y`，而不是每帧手动修改集合中心。

## 手动测试

在项目根目录运行：

```text
godot --path .
```

操作：

- `A/D`：移动，观察自由胶球和角色集合的液体流动。
- `Space`：跳跃，观察角色动画及集合底部是否稳定。
- 鼠标左键：吐出胶球，检查胶球约为角色可见高度的 40%。
- 鼠标右键：吸收地面胶球，观察集合逐步变大。
- `R`：重置测试场景。

重点检查：

1. 自由胶球不是简单缩放，边缘和内部有持续变化。
2. 胶球静止两秒后仍是液体形变，同时缓慢膨胀到约 1.35 倍。
3. 玩家集合数量增加时，底部不下移。
4. 角色贴图双腿没有被集合完全遮住。
5. 集合接近最大数量时仍然是一个连续的融球形状。
