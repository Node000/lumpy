# 液体视觉调参说明

项目的视觉参数集中在 `scripts/core/gameplay_tuning.gd`。修改后重新运行项目即可看到结果；如果修改了 builder 中的场景初始值，需要重新运行对应 builder。

## 常用参数

### 角色贴图大小

角色贴图由 `builders/build_player_test.gd` 创建，搜索：

```gdscript
animated.scale = Vector2(0.72, 0.72)
```

- `0.72` 改大，角色贴图整体变大。
- `0.72` 改小，角色贴图整体变小。
- 例如 `Vector2(0.85, 0.85)` 会比当前大约 18%。
- 贴图原点由 `animated.position` 控制：

```gdscript
animated.position = Vector2(0, -15)
```

第二个数变小，贴图向上移动；变大，贴图向下移动。

修改后运行：

```text
godot --headless --path . --script res://builders/build_player_test.gd
```

### 自由胶球大小与喷吐

胶球是颗粒制：角色身上的胶球以"颗"计数。按住鼠标左键会持续逐颗喷出小球，松开即停止。

在 `scripts/core/gameplay_tuning.gd` 中调整：

```gdscript
var glue_ball_radius := 6.0
var glue_ball_collision_radius := 4.2
var spit_interval := 0.12
var spit_speed := 540.0
var spit_spread_deg := 6.0
```

- `glue_ball_radius`：单颗粒视觉半径（当前 6）。
- `glue_ball_collision_radius`：单颗粒碰撞半径，当前为 `4.2`，比 `6.0` 的视觉半径小 30%，让小球之间和小球与墙面的碰撞更宽松。改回 `6.0` 可恢复与视觉同半径。
- `spit_interval`：连续喷吐时两颗球之间的间隔（秒）。
- `spit_speed`：小球飞行速度。
- `spit_spread_deg`：每颗球的发射方向散布（全角）。

### 颜料摊开与堆积

```gdscript
var glue_splat_spread := 12.0  # 沿墙面切向摊开幅度
var glue_splat_forward := 6.0  # 顺墙面法线向前弹出
```

颗粒撞粗糙墙/地面后沿墙面切向随机散开再静止，多次命中叠加形成堆积效果。调大 `glue_splat_spread` 摊开更宽；调小则堆得更紧。

### 胶球静止表现

胶球静止一段时间后会**弹性放大**（先冲过目标尺寸再回弹到最终大小），视觉与碰撞按同一倍数同步增长；不使用起伏、收缩、呼吸或液体 shader。

在 `scripts/core/gameplay_tuning.gd` 中调整：

```gdscript
var glue_swell_delay := 2.0       # 静止多久后开始弹性放大（秒）
var glue_swell_scale := 2.0       # 放大后的最终倍数（视觉 + 碰撞）
var glue_swell_anim_time := 0.5   # 弹性动画时长（秒）
```

- `glue_swell_delay`：静止后等待多久再开始放大。
- `glue_swell_scale`：最终放大倍数；改回 `1.0` 可完全关闭膨胀。
- `glue_swell_anim_time`：弹性动画持续时间，越长回弹越慢。

### 胶球集合大小

角色身上的胶球以颗粒计数。集合由每颗胶球对应的独立
`BlobSprite` 构成，最多显示 `max_glue` 颗粒；碰撞也使用同一套位置和半径，
作为一个 `CharacterBody2D` 的复合身体参与物理。

```gdscript
var max_glue := 120           # 身上颗粒总量上限（HUD 显示 x/120）
var start_glue := 30          # 起始颗粒数
var player_collection_radius_base := 15.0
var player_collection_radius_per_glue := 0.24
var player_collection_max_radius := 46.0
```

- `player_collection_radius_base`：基础集合半径。
- `player_collection_radius_per_glue`：每颗颗粒增加的集合半径。
- `player_collection_max_radius`：集合最大半径。

### 颗粒重量与跳跃

```gdscript
var glue_effect_cap := 90          # 重量达到 90 颗时衰减拉满
var glue_jump_weight_max := 0.5    # 最高衰减 50%（最多跳一半高）
```

颗粒越多，跳跃越低：`jump_velocity × (1.0 - glue_jump_weight_max × 颗粒数/90)`。

### 集合底部位置

```gdscript
var player_collection_bottom_y := 14.0
```

这个值是相对玩家根节点的局部 Y 坐标：

- 数值增大，集合整体向下，底部更靠近脚。
- 数值减小，集合整体向上，脚部露出更多。
- 增长过程中底部会保持在这个位置，集合中心会自动向上移动。

### 胶球视觉

自由胶球和角色身上的颗粒都使用固定轮廓，不再使用液体扭曲、流动、起伏、收缩或呼吸动画。

### 融球颜色与渲染层级

```gdscript
var player_body_color := Color(0.98, 0.965, 0.953, 1.0)
```

- `player_body_color`：玩家身上融球集合的颜色，默认与角色贴图身体色一致。
- 集合的 `z_index` 为 `3`，角色贴图 `z_index` 为 `2`，因此融球集合会覆盖在贴图上方。
- 如果想让贴图重新覆盖融球，调整 `scripts/gameplay/blob_backdrop.gd` 中的 `z_index = 3` 为小于 2 的值（例如 `1`）。

### 玩家颗粒集合

玩家身上的集合由多个独立静态小球构成，按确定性的圆盘布局排列。布局会随
集合半径更新，但不会每帧改变粒子相对位置，因此碰撞体不会抖动。

关键参数（`scripts/core/gameplay_tuning.gd`）：

```gdscript
var collection_bubble_radius := 6.0
```

- `collection_bubble_radius`：每颗环绕小球的半径。

粒子布局逻辑在 `scripts/gameplay/blob_backdrop.gd` 的 `_build_layout()`：

- 所有颗粒都是胶粒，没有单独的视觉核心。
- 集合最下方的第一颗胶粒是脚部锚点，始终与底部基准线相切。
- 增加胶球数量时，新小球会加入已有布局，不会改变已存在小球的编号。

想改变观感：

- 想让小球更明显：调大 `collection_bubble_radius`。
- 想让小球聚得更紧：调小 `player_collection_radius_per_glue` 或 `player_collection_max_radius`。

### 碰撞箱大小

玩家不再使用一个随胶量放大的大圆。`Player` 根节点直接拥有一个（不随胶量
变化的）固定身体碰撞体 `Collision`，以及每颗可见胶粒对应的
`ParticleCollisionXXX`。这些圆形形状由 `BlobBackdrop` 的同一份布局同步，
Godot 会把它们作为一个复合身体处理。集合底部由 `player_collection_bottom_y`
锚定，脚部颗粒的下缘保持在这条基准线上。

`body_radius_base` 现在只用于固定身体碰撞体的半径。玩家的复合碰撞边界由
`player_collection_radius_base`、`player_collection_radius_per_glue`、
`player_collection_max_radius` 和 `player_collection_bottom_y` 决定。

### 吸球扇形角度与鼠标指向

```gdscript
var suck_cone_angle_deg := 30.0
var suck_range := 430.0
var show_suck_range := true
```

- `suck_cone_angle_deg`：吸球扇形**全角**，一半为 `15°`，默认 `30°`。
- `suck_range`：吸取半径，角色为扇形中心点。
- `show_suck_range`：是否在按住右键时显示扇形范围。
- 扇形中心线 360° 跟随鼠标位置；按住右键移动鼠标即可旋转。
- 吐球与吸球一样，弹丸方向跟随鼠标 360° 旋转。
- 调大 `suck_cone_angle_deg`（如 `60.0`）扇形变宽；调小（如 `15.0`）变窄。
- 被吸中的胶球会关闭碰撞，直接穿过墙体和其他对象飞向角色。

### 吸取胶球参数

吸取参数都在 `scripts/core/gameplay_tuning.gd` 的 `# Suck` 区域：

```gdscript
var suck_cone_angle_deg := 30.0
var suck_range := 430.0
var suck_speed := 760.0
var max_suck_glue := 24
var suck_recast_time := 0.10
var show_suck_range := true
```

- `suck_cone_angle_deg`：吸取扇形的**全角**。例如 `60.0` 会变宽，`15.0` 会变窄；数值越大，越容易吸到偏离鼠标方向的球。
- `suck_range`：吸取检测半径，单位是世界像素。增大可吸得更远，也会扩大屏幕上的范围指示。
- `suck_speed`：胶球回到玩家的速度，单位是世界像素/秒。增大后回收更快。
- `max_suck_glue`：每次扫描最多锁定的胶球数量；按住右键时会按 `suck_recast_time` 周期重新扫描。
- `suck_recast_time`：连续吸取的重新扫描间隔，单位是秒。调小会更频繁地抓取新球。
- `show_suck_range`：按住右键时是否显示扇形范围；设为 `false` 只关闭辅助显示，不影响实际吸取。

吸取方向跟随鼠标，扇形中心线可以覆盖 360°。被锁定的球会暂时关闭自身碰撞并直线回到玩家，因此不会被墙体或其他胶球挡住。

## 胶球集合中心对象位置

集合是玩家节点 `VisualBlob` 下的静态 `BlobSprite` 节点，布局逻辑在
`scripts/gameplay/blob_backdrop.gd` 的 `_build_layout()`。

- X 为左右位置，负数向左，正数向右。
- Y 为相对集合中心的位置，负数向上，正数向下。
- 第一颗胶粒放在集合最下方，作为脚部锚点。
- 其余胶粒使用黄金角填充圆盘，位置和半径同步给 `Player` 的复合碰撞形状。
- 不建议直接修改 `VisualBlob.position`，因为它会破坏底部锚定公式。

底部锚定公式是：

```gdscript
position.y = _bottom_y - radius
```

如果需要整体调整集合底部，请改 `player_collection_bottom_y`，而不是每帧手动修改集合中心。

## 手动测试

在项目根目录运行：

```text
godot --path .
```

操作：

- `A/D`：移动。
- `Space`：跳跃，观察颗粒越多跳越低的效果。
- 按住鼠标左键：持续逐颗喷吐，方向有轻微散布。
- 按住鼠标右键：吸收扇形范围内的颗粒。
- 击打墙面：观察颗粒摊开与堆积。
- `R`：重置测试场景。

重点检查：

1. 自由胶球静止约 2 秒后弹性放大到 2 倍大小，边缘保持平滑圆形。
2. 按住左键时胶球按间隔逐颗发射，而不是一次生成一团。
3. 玩家集合数量增加时，底部不下移。
4. 角色贴图双腿没有被集合完全遮住。
5. 集合接近最大数量时仍然是一个连续的融球形状。
