# 基础操作与胶球原型实现说明

## 已实现

- A/D 水平移动，带加速与减速。
- Space 变高度跳跃，支持跳跃缓冲、土狼时间、松键截断；**身上颗粒越多跳得越低**（最高衰减 50%）。
- 左键吐胶球：按住左键会按间隔逐颗喷出小球（视觉半径 6，碰撞半径 4.2），每颗以鼠标指向为方向带轻微角度散布。
- 右键吸胶球：以鼠标指向为中轴，在可调全角和半径的扇形内筛选多颗胶球（中心线 360° 跟随鼠标，上限 24 颗）；按 `show_suck_range` 可开关范围显示。
- 被吸中的球会关闭碰撞，直接穿过墙体和其他对象飞回玩家，不再进行墙体视线或回程碰撞检测。
- 颗粒命中粗糙墙/地面后静止；光滑墙反射并继续运动。
- 胶球撞粗糙墙停止飞行后切换到 `glue_rest` 碰撞层，碰撞形状保持启用，仍可作为平台并参与后续碰撞。
- 胶球 FLY / STUCK / SUCK 状态。
- 飞行球撞粗墙或胶球后静止；撞光滑墙后按法线反射并继续飞行。
- 静止胶球可作为玩家平台；静止 `glue_swell_delay` 秒后会弹性放大到 `glue_swell_scale` 倍（视觉与碰撞同步），不使用液体 shader、起伏、收缩或呼吸。
- 玩家身上的集合由逐颗独立的 `BlobSprite` 构成（没有单独的视觉核心圆），`Player` 使用与视觉布局同步的复合圆形碰撞体，并保留一个固定身体碰撞体防止 0 胶球时穿地。胶量仍会影响跳跃高度。
- 对象池预生成 48 颗球，避免反复创建和销毁。
- 每个墙体脚本自带 `smooth` 属性，测试场景用不同颜色区分粗糙墙和光滑墙。

## 测试场景

- `res://scenes/levels/player_test.tscn`
  - 默认启动场景。
  - 包含粗糙地面、光滑墙、平台、4 颗可吸胶球和 HUD。
  - 操作提示写在画面左上角。
- `res://scenes/levels/shader_test.tscn`
  - 演示独立的液态/融球 shader 实验，不用于游戏中的自由胶球。
  - 演示多球 metaball 阈值融合 shader。
  - 面板可调 blobs、radius、surface、edge、wobble、drift；按钮可重新散布球体，按 H 隐藏面板。

## Shader 可行性结论

当前 shader 测试场景验证的是**视觉可行性**，不是最终生产版融球系统。

- 游戏中的自由胶球使用静态圆形；shader 实验场景仅用于独立视觉验证。
- metaball shader 使用固定上限 24 个球，通过 uniform 数组传递中心位置，每帧做场函数求和并阈值化。
- 该 shader 测试场景作为独立视觉实验保留；实际玩家集合使用独立粒子节点，避免 shader 源点上限和视觉/碰撞不同步。
- 玩家集合的视觉和碰撞共用 `BlobBackdrop` 的局部布局，shader 调整不会影响基础操作。

## 统一调参

当前调参入口是 autoload：`res://scripts/core/gameplay_tuning.gd`，包含移动、跳跃、胶球数量、发射、吸球和视觉参数。

## 大地图与房间相机

- `player_test.tscn` 是手绘大地图：11 张 1920×1080 房间图按 3 列铺开。
- 每个房间在 `RoomCamera` 下有一个 `RoomRegion` 标记节点，手调 `room_rect`
  与节点位置即定义房间范围；`_draw` 会在**编辑器**里画出半透明框方便可视化，
  游戏运行时不会渲染任何标记。
- `RoomCamera` 开局 snap 到玩家所在房间的焦点；玩家跨入相邻房间时镜头平滑
  pan 过去；同一房间内镜头锁定在房间中心（一房一屏）。
- 缩放按当前窗口自动适配（`fill_ratio`，默认让整房占视口 90%，取限制轴），
  窗口改变大小时重新计算。
- 用 `RoomRegion` 的可选 `focus_override` 可让镜头对准房间内任意点。

## 验证命令

```text
Godot_v4.7.1-stable_win64_console.exe --headless --path . --import
Godot_v4.7.1-stable_win64_console.exe --headless --path . --script res://tests/test_player_glue.gd
Godot_v4.7.1-stable_win64_console.exe --headless --path . --script res://tests/test_room_camera.gd
```

场景由 builder 生成：

```text
builders/build_glue_ball.gd
builders/build_player_test.gd
builders/build_shader_test.gd
```

退出时 builder 可能输出 RID/resource 泄漏诊断，这是 headless builder 在进程退出时留下的临时构建对象；场景构建成功、项目运行和行为测试均以退出码与运行期错误为准。
